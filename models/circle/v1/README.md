Player-finding files for the Labs feature "Circle my player in highlights".
They run on the phone; nothing about the players leaves it.

- yolox_nano.onnx: YOLOX-nano person detector (Megvii, Apache License 2.0), unchanged from the 0.1.1rc0 release.
- parseq_tiny_len3.onnx and ios/ParseqTiny.mlmodelc: PARSeq tiny scene-text reader (Darwin Bautista, Apache License 2.0), exported for up to 3 characters.
- parseq_charset.json: the reader's character list.
